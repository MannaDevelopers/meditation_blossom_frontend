# Issue #300: 묵상 질문 선택 복사 - 줄 단위 제한 해제 + 전체 복사 버튼 추가 (FE) — 구현 계획

**Goal:** 매일 만나 화면의 "묵상 질문" 영역에서 (1) 질문 줄 경계와 상관없이 자유롭게 드래그 선택할 수 있게 하고, (2) 섹션 제목 옆에 복사 버튼을 추가해 눌렀을 때 묵상 질문 전체를 클립보드에 복사 + 토스트를 띄운다(말씀 제목 옆 복사 버튼과 동일 패턴).

**원인:** `DailyMannaScreen.tsx`가 `meditationQuestions.map(...)`으로 질문마다 별도 `SelectableText` 인스턴스를 그리고 있어([ISSUE-298]/#299), 플랫폼 선택 메커니즘(Android `Text selectable` / iOS 읽기 전용 `TextInput`)이 컴포넌트 단위로 동작하는 한 선택도 컴포넌트(=줄) 경계를 못 넘는다. `PassageBlock`이 본문 전체를 하나의 `SelectableText`로 그려 자유 선택이 되는 것과 같은 원리로, 질문들을 하나의 블록으로 합치면 해결된다.

**Tech Stack:** TypeScript, React Native.

**테스트 정책:** 순수 함수(`copyText.ts`)는 유닛 테스트 추가. 화면 컴포넌트 변경은 코드 리뷰 + PR 체크리스트로 수동 검증(에뮬레이터 미보유 환경 가정, 리뷰어 확인 항목 명시).

**커밋 정책:** `feature/issue-300` 브랜치, 커밋 메시지 `[ISSUE-300] type: 설명`.

## Tasks

### Task 1: `copyText.ts`에 질문 전용 복사 텍스트 빌더 추가

**File:** `src/utils/copyText.ts`

`buildFullCopyText`가 묵상 질문 블록을 인라인으로 조립하던 부분(`['묵상 질문', ...asked.map(q => \`- ${q}\`)].join('\n')`)을 재사용 가능한 함수로 뽑는다. 섹션 복사 버튼과 전체 복사 버튼이 동일한 포맷(헤더 + "- " 불릿)을 쓰게 하기 위함.

```ts
/**
 * 묵상 질문 섹션 복사 버튼 · 전체 복사 버튼이 공유하는 포맷.
 * 빈 질문은 제외한다.
 */
export function buildQuestionsCopyText(questions: string[]): string {
  const asked = questions.map(q => q.trim()).filter(Boolean);
  return ['묵상 질문', ...asked.map(q => `- ${q}`)].join('\n');
}
```

`buildFullCopyText` 내부의 인라인 조립을 `buildQuestionsCopyText(questions ?? [])` 호출로 교체(빈 배열이면 `blocks.push` 안 하도록 길이 체크는 유지).

### Task 2: 묵상 질문을 단일 `SelectableText` 블록으로 병합 (줄 경계 없는 선택)

**File:** `src/screens/DailyMannaScreen.tsx`

현재 (241~250행):
```tsx
{meditationQuestions.map((question, index) => (
  <View key={index} style={styles.questionCard}>
    <Text style={styles.questionNumber}>
      {index === 0 ? '•' : ''}
    </Text>
    <SelectableText text={question} style={styles.questionText} />
  </View>
))}
```

각 질문이 독립된 `SelectableText`라 선택이 행 단위로 끊긴다. `PassageBlock`이 본문 전체를 줄바꿈 포함 단일 문자열로 넘기는 것과 같은 방식으로, 질문 배열을 `\n`으로 합쳐 **하나의** `SelectableText`에 전달한다:

```tsx
<View style={styles.questionCard}>
  <Text style={styles.questionNumber}>•</Text>
  <SelectableText text={meditationQuestions.join('\n')} style={styles.questionText} />
</View>
```

- 기존에도 `•`는 첫 줄에만 있었으므로(다른 줄은 빈 문자열) 시각적으로 달라지지 않는다 — 단일 블록으로 합쳐도 레이아웃은 동일.
- `.map`/`key={index}` 제거로 `View`가 하나만 렌더된다.
