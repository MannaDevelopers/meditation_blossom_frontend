# Main App
1. 첫 페이지는 주일말씀탭과 매일만나 탭으로 구성되어있다.
2. 첫 페이지에는 앱 제목인 "묵상만개" 가 표시되어있다.
3. 첫 로딩시 서버에서 가져온 말씀 데이터가 잘 표시되어 있다.
4. 포그라운드 상태에서 테스트 FCM 을 보냈을 때 해당 메시지 내용으로 말씀 내용이 잘 업데이트 된다.(테스트 FCM 토큰은 "sermon_events", "qt_events")
5. 설정 버튼을 눌렀을 때 설정 페이지로 잘 이동한다.

# Widget - Android
1. 메인 앱 백그라운드 상태에서 테스트 FCM 을 보냈을 때 해당 메시지 내용으로 말씀 내용이 잘 업데이트 된다.(테스트 FCM 토큰은 "sermon_events", "qt_events")
2. 위젯 종류는 "Daily QT (Card)", "이번 주 말씀 (카드형)", "Daily QT (Banner)", "이번 주 말씀 (배너형)" 이다.
